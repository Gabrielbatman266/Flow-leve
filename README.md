# Flow Leve ⚡

Script que deixa o Google Flow mais leve no celular.

## Instalar (1 toque)

1. Instale o **Firefox** no celular e, dentro dele, a extensão **Violentmonkey** ou **Tampermonkey**.
2. Abra este link no Firefox e toque em **Instalar**:

   **https://raw.githubusercontent.com/Gabrielbatman266/Flow-leve/main/flow-leve.user.js**

3. Entre no Flow pelo Firefox. Vai aparecer um botão ⚡ no canto da tela.

As atualizações chegam sozinhas.

## O que ele faz

- **Modo leve:** desliga animações, desfoques e sombras.
- **Prévias pausadas:** os vídeos da galeria só tocam quando você toca neles.
- **Liberar memória:** tira da memória os vídeos que saem da tela.
- **↺ Reutilizar prompt:** botão verde com seus últimos prompts. Toque num prompt pra colocá-lo de volta na caixa; ☆ fixa no topo, 📋 copia, 🗑 apaga.
- **Voltar não sai do projeto:** o botão voltar do celular fecha menus e janelas primeiro; pra sair do projeto, toque voltar 2x.
- **Manter tela ligada:** evita que a aba congele no meio da geração (ative no menu ⚡).

Se alguma coisa quebrar, desligue o **Modo leve** no menu ⚡.
